## 🚆 Bilet Bot — охотник за ж/д билетами по Узбекистану

> Билетов на Ташкент → Самарканд «нет»? Бот дождётся, когда они появятся, и сразу напишет в Telegram.

Telegram-бот, который круглосуточно мониторит наличие мест на поезда **UTY (Узбекистон темир йуллари)** и присылает уведомление в ту же минуту, когда появляются подходящие билеты — пока их не разобрали.

**Что умеет**

- 🔍 **Гибкий поиск** — 18 станций (Ташкент, Самарканд, Бухара, Хива, Ургенч, Нукус, Андижан, Термез и др.), дата на 3 недели вперёд
- 🎯 **Точные фильтры** — тип вагона (сидячий / плацкарт / купе / СВ), максимальная цена, минимум свободных мест, конкретный номер поезда (Afrosiyob, Sharq…)
- ⏱ **Мониторинг 24/7** — проверка от раза в минуту до раза в 30 минут, отдельно для каждого поиска
- 🔔 **Умные уведомления** — пишет только когда появились *новые* места, без спама одним и тем же
- 📋 **Управление поисками** — несколько поисков одновременно, пауза, удаление, смена частоты прямо в чате
- 🔎 **Ручная проверка** — одна кнопка, чтобы проверить всё прямо сейчас
- 🛡 **Бережно к сайту** — очередь запросов с паузами, автообновление сессии, приватный доступ по whitelist

**Как это выглядит**

```
Вы:   ➕ Новый поиск → Ташкент → Самарканд → 28.11 → Купе → до 400 000 сум
Бот:  ✅ Поиск #3 создан. Проверяю каждые 2 мин.
...
Бот:  🎉 Появились места!
      🚆 764Ф Afrosiyob 08:00→10:10
         Купе: 4 места, 357 000 сум
      👉 Купить: eticket.uzrailpass.uz
```

**Стек:** Python · aiogram 3 (FSM) · aiohttp · SQLite · asyncio-планировщик · Cloudflare Workers + D1 (serverless-версия)
